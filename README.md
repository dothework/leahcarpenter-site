# leahcarpenter.com

Practical AI consulting — the business site for Leah Carpenter.

**Live:** https://leahcarpenter.com

## Stack

Plain static site — HTML, CSS, and a small amount of JavaScript. No build step, no dependencies, hosted on GitHub Pages.

- `index.html` — page structure and content
- `styles.css` — design system (Fraunces + Inter + JetBrains Mono, ivory + coral palette)
- `app.js` — animated signal-wave motif in the hero
- `CNAME` — custom domain configuration

## Editing

Edit files and push to `main`. GitHub Pages redeploys automatically within about a minute.
