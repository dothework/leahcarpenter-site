# leahcarpenter.com

Practical AI consulting — Leah Carpenter's business site.

**Live:** https://leahcarpenter.com
**Also hosted at:** https://leahcarpenter.pplx.app (Perplexity preview mirror)

## Stack

Plain static site — HTML, CSS, and a tiny bit of JavaScript. No build step, no dependencies.

- `index.html` — page structure and content
- `styles.css` — design system (Fraunces + Inter + JetBrains Mono, ivory + coral palette)
- `app.js` — animated "signal" motif in the hero
- `CNAME` — tells GitHub Pages the custom domain

## Editing

Edit files directly and push to `main`. GitHub Pages redeploys automatically within about a minute.

## Design direction

Editorial + Signal — an ivory print-magazine surface with one saturated coral accent (`#D64545`), display serif, mono captions, and a subtle animated signal-wave motif. Portrait-optional layout.
